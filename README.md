# Technical Reference Guide

A single-file interactive reference for IT break/fix and systems engineering work.

## What's inside
- Commands, walkthroughs and data flow diagrams, grouped by environment: Help Desk & Breakfix, Networking, On-Prem, Hybrid, Cloud, Security, Coding & Dev Practices, Languages & Databases, and AI & Automation
- Systems engineer tools: HEALTHsuite, AIX, Db2, ROC Maestro, GoAnywhere
- Risk badges, source links, and a Copy button on every command

## How to use it
- Search by keyword, or narrow with the Filters button (risk, category, topic)
- Use Contents to jump to a section
- Everything starts collapsed. Click a title to open it

## Open it
- Live page (after enabling GitHub Pages): https://zedzith.github.io/technical-reference-guide/
- Or download `index.html` and open it in any browser. No install needed

## Notes
- Links have not all been tested
- HEALTHsuite, GoAnywhere and ROC Maestro flows are generic. Check them against your environment
- AI model names change often
